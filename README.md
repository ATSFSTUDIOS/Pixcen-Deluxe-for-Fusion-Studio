# Pixcen Deluxe for Fusion Studio

## Overview

Pixcen is a retro Commodore C64 16-color focused bitmap image editor and dithering toolset for Windows.

This repo holds a BMD Fusion Studios focused fork of the Pixcen Deluxe development repository. The purpose of the fork is to explore way to improve how the Pixcen software integrates with 3rd party DCC tools.

## Downloads

Official Precompiled binaries for Windows can be downloaded from:
https://binarybone.com/pixcen/pixcen.zip

## Compiling Pixceb from Source

To build Pixcen's source code, it is recommend to clone this repository using either the "GitHub Desktop" app, or the "git" CLI (vommand line interface).

Then download and use Microsoft's free "Visual Studio 2022 Community Edition" development tools on Windows 10/11.
